# 0.15.0

**Tag:** `v0.15.0` · **Date:** 2026-11-15

All changes since [`v0.14.0`](v0.14.0.md).

A .NET 10 servicing and dependency refresh with no source changes, no test-code changes, and no public API changes. The scope is deliberately the latest .NET 10 lines, not .NET 11: .NET 11 shipped on 2026-11-10 and nuget.org now carries 11.0.0 majors that this release does not take. All four packages ship at 0.15.0 in lockstep, and the satellites depend on core `>= 0.15.0`. That core floor is the only consumer-visible nuspec change; every third-party floor is unchanged. No Dependabot or other PR was open when this release was cut (`gh pr list --state open` returned `[]`), so it supersedes nothing.

## Changed

- **`global.json` SDK 10.0.403 → 10.0.404**: the latest .NET 10 SDK, from the .NET 10.0.15 release on 2026-11-10, which the .NET release-metadata index (`builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json`) flags `security: true` with 16 CVEs. The same release also ships SDK 10.0.115. `rollForward: latestFeature` and the `test` section (Microsoft Testing Platform) are unchanged. CI resolves the SDK through `actions/setup-dotnet` with `global-json-file: global.json`, so CI now builds on 10.0.404; the publish job's `dotnet-version: '10.0.x'` is unchanged. The repo stays on the .NET 10 SDK.
- **`Microsoft.Extensions.Configuration.Binder`, `Microsoft.Extensions.Configuration.Json`, and `Microsoft.Extensions.Hosting` 10.0.14 → 10.0.15** (`Directory.Packages.props`; published on nuget.org 2026-11-10). Only tests and samples reference these: the integration-test projects, both demos, and `tests/Andes.Extensions.AI.TestMcpServer`. None of the four shipped projects references them, directly or transitively.
- **`Microsoft.NET.Test.Sdk` 18.11.0 → 18.12.0** (`Directory.Packages.props`; published 2026-11-11; test-only). VSTest is not versioned with .NET, and the package's nuspec dependency groups are `net8.0` and `.NETFramework4.6.2`, so this is not a .NET 11 package. Version 18.11.1 (2026-11-10) also exists and was skipped in favor of the newest stable.
- **Deliberately held** (the newest version on nuget.org is a .NET 11 major, or a minor the pin comment forbids):
  - `Microsoft.Extensions.AI`, `.Abstractions`, and `.OpenAI` stay at 10.11.0, the newest 10.x. Version 11.0.0 was published 2026-11-10.
  - `Microsoft.Extensions.Configuration.*` and `Microsoft.Extensions.Hosting` stay on the 10.0.x line (now 10.0.15). Version 11.0.0 was published 2026-11-10.
  - `OpenAI` stays at 2.14.0. Version 2.15.0 was published 2026-11-05, but `Microsoft.Extensions.AI.OpenAI` 10.11.0 is still the newest 10.x and compiles against OpenAI 2.14.0, so the pin comment in `Directory.Packages.props` and the Dependabot ignore rule still apply.
  - The Dependabot config already ignores semver-major updates for every dependency, so it will not propose the 11.0.0 majors.
- **Already latest stable, unchanged:** `Microsoft.Agents.AI` 1.28.0, `ModelContextProtocol` and `ModelContextProtocol.Core` 2.4.0 (the pair stays equal), `xunit.v3` 4.0.3, `xunit.runner.visualstudio` 4.0.1, `Spectre.Console` 0.57.2, and `Azure.AI.OpenAI` 2.1.0.
- **Version bump:** `<Version>` goes 0.14.0 → 0.15.0 in the four package csprojs.
- **Consumer-visible floors, read from the packed nuspecs:**
  - Core: `Microsoft.Extensions.AI >= 10.11.0` and `Microsoft.Extensions.AI.Abstractions >= 10.11.0` (unchanged).
  - Mcp: core `>= 0.15.0` (was 0.14.0), `ModelContextProtocol.Core >= 2.4.0`, and both Microsoft.Extensions.AI packages `>= 10.11.0`.
  - Agent: core `>= 0.15.0` (was 0.14.0), `Microsoft.Agents.AI >= 1.28.0`, and both Microsoft.Extensions.AI packages `>= 10.11.0`.
  - UI: core `>= 0.15.0` (was 0.14.0) and both Microsoft.Extensions.AI packages `>= 10.11.0`.
- **Transitive moves per project** (`dotnet list package --include-transitive`, before versus after):
  - The four shipped projects (core, Mcp, Agent, UI) have none.
  - All six test projects with a test SDK reference: `Microsoft.NET.Test.Sdk`, `Microsoft.CodeCoverage`, `Microsoft.TestPlatform.ObjectModel`, and `Microsoft.TestPlatform.TestHost` move 18.11.0 → 18.12.0.
  - The three integration-test projects and both demos: the `Microsoft.Extensions.Configuration*` family, `Microsoft.Extensions.FileProviders.*`, `Microsoft.Extensions.FileSystemGlobbing`, and `Microsoft.Extensions.Primitives` move 10.0.14 → 10.0.15.
  - `Andes.Extensions.AI.TestMcpServer` and `Andes.Extensions.AI.Mcp.Integration.Test` (through Hosting) additionally move the Hosting, DependencyInjection, Diagnostics, Logging (including Console, Debug, EventLog, and EventSource), and Options families, plus `System.Diagnostics.EventLog`, 10.0.14 → 10.0.15.
- **Docs updated to the actual floors**: [`docs/agents.md`](../docs/agents.md), [`docs/mcp.md`](../docs/mcp.md), and [`docs/ui.md`](../docs/ui.md) now state core `>= 0.15.0` (previously `>= 0.14.0`). Their third-party floors (`Microsoft.Agents.AI >= 1.28.0`, `ModelContextProtocol.Core >= 2.4.0`) are unchanged. The `AGENTS.md` project section now says the four packages are at 0.15.0.
- **All four packages version in lockstep at 0.15.0; the satellites depend on core `>= 0.15.0`.**
